SETTING UP THE PREPFIX CHURCH MEDIA TOOLKIT ON ANOTHER LAPTOP
=======================================================

ONE TIME, on your laptop (prepare the flash disk)
-------------------------------------------------
1. Copy node.exe into the toolkit folder:
     - Open  C:\Program Files\nodejs
     - Copy the file  node.exe
     - Paste it into the toolkit folder (next to server.js)
   Now the folder carries everything it needs. Nothing has to be installed anywhere.
2. Copy the whole toolkit folder to a flash disk.
   (You can leave out: "old version (before update)", "New folder", data.backup.json)


ON THE NEW LAPTOP (anyone can do this)
--------------------------------------
1. Copy the toolkit folder from the flash disk to the Desktop.
   (Run it from the Desktop, NOT from the flash disk.)
2. Open the folder and double-click  "0 START PREPFIX CHURCH"  (the first file in the list)
3. Windows should not ask anything. (Only if the toolkit came as a zip from the internet: before unzipping,
   right-click the zip > Properties > tick "Unblock" > OK. If a blue box "Windows protected your PC"
   still shows once: click "More info", then "Run anyway". After the first start it never comes back.)
4. If Windows asks about the firewall ("Allow access?"):
      tick Private networks and click "Allow". (Needed for phones to connect.)
5. A black window opens - LEAVE IT OPEN. The control page opens by itself.
   From now on there is a "Prepfix Church" icon on the Desktop (and a "START PREPFIX CHURCH" icon in the
   folder) with a gold cross, to start it.

All songs, playlists, settings and the church wallpaper come along inside the folder.


EVERY SUNDAY
------------
1. Connect the projector cable. Press Windows key + P and choose "Extend".
2. Double-click "Prepfix Church" (gold cross icon) on the Desktop.
   - The lyrics screen opens full screen on the projector by itself.
   - The control page opens on the laptop.
3. Pick a song, tap the line numbers (or Next line / Next stanza).
4. Hide lyrics = projector shows the normal desktop. Show lyrics = lyrics come back.
5. After the service: close the black window. That closes everything.


IF SOMETHING GOES WRONG
-----------------------
- "Node.js was not found": node.exe is missing from the folder - copy it in (step 1 above).
- Lyrics not on the projector: press Windows key + P > Extend, then press "Show on projector".
- Phone cannot connect: phone and laptop must be on the same Wi-Fi; use the address
  shown in the black window (e.g. http://192.168.1.20:3000).
